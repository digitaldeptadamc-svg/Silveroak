Silver oak
Botanical Name :

  • Grevillea robusta

    • Family Name :

  • Proteaceae

    • Local Name :

  • Silver Oak

    • Vernacular Name :

  • Hindi – Silver Oak

  • English – Silver Oak

    • Habitat :

  • Native to Australia; widely cultivated in India in plantations, roadsides, and as a shade tree

  • Grows well in tropical and subtropical climates


    • Morphology :

  • Tall evergreen tree (up to 30–40 m)

  • Leaves: Fern-like, deeply divided, silvery underside

  • Flowers: Golden-yellow/orange, brush-like clusters

  • Bark: Dark grey, rough

  • Wood: Moderately strong


    • Useful Parts :

  • Leaves

  • Wood


    • Chemical Constituents :

  • Phenolic compounds

  • Tannins


    • Actions :

  • Mild antimicrobial

  • Ornamental

  • Shade-providing


    • Properties :

  • Used as timber

  • Provides shade in plantations

  • Soil improvement (Leaf litter)


    • Uses :

  • Agroforestry

  • Ornamental planting
